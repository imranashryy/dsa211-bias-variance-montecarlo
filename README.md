## Overview

A Monte Carlo study of how bias², variance and irreducible error make up expected test error as model complexity grows. Because the data are simulated from a known function, bias and variance can be measured exactly against the truth, which is impossible with real data.

## Research questions

**Main question:** How do bias², variance and irreducible error contribute to expected test error as the degree *d* of a polynomial regression (fitted by OLS) rises from 1 to 10?

1. **Decomposition.** How do bias² and variance change with *d*, and does bias² + variance + σ² reproduce the expected test MSE?
2. **Optimal complexity.** Which degree minimises expected test error, and does it match the true degree of 3?
3. **Noise.** How does the optimal degree shift as σ rises from 0.2 to 1, and what does that imply when σ is unknown?
4. **Regularisation.** With a LASSO path on an effective-degrees-of-freedom axis, how does its bias–variance profile compare with polynomial OLS?

## Data-generating process

| Component | Setting |
|---|---|
| True function | f(x) = x³ − x (true degree 3) |
| Inputs | X ~ U(−1, 1) |
| Noise | ε ~ N(0, σ²), Y = f(X) + ε |
| Noise levels | σ = 0.3 (baseline); 0.2, 0.5, 1 (extension) |
| Training size | n = 50 per run |
| Simulation | R = 500 runs, 200 fixed test inputs, fresh test noise in every run |
| Models | Polynomial OLS, degree 1–10; LASSO on the standardised powers x, …, x¹⁰ (40 penalties) |

## Course methods applied

- Polynomial regression by OLS (Weeks 2–4), fitted with the Lab 7 pipeline: `StandardScaler` → `PolynomialFeatures` → `LinearRegression`
- Bias–variance decomposition of expected test error (Week 1)
- Train/test discipline, k-fold cross-validation and the one-standard-error rule (Weeks 7–8)
- LASSO with standardised predictors, fitted one penalty at a time (Week 9)
